description: "The deprecated API version, kept for existing integrations until October 1, 2027"
---

<Warning>
  Version `2026-09` is deprecated and stops working on October 1, 2027. We recommend `2026-10` for new integrations.
</Warning>

These pages describe the API exactly as it was before date-based versioning. They stay available for integrations that still send `Sajn-Version: 2026-09`, or whose organization default is `2026-09`.

To move your integration, see [Upgrading to 2026-10](/upgrading/2026-10). For how versions work, see [API versioning](/api-fundamentals/versioning).
