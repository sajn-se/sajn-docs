---
title: "Activity events"
description: "Every entry type in a document's activity log, the audit trail behind the signing journal"
---

sajn records everything that happens to a document in its **activity log**: who sent it, who opened it, how each party verified their identity, and when the PDF was sealed. The log is the source of the signing journal and the timestamps on the [signing certificate](/concepts/signing-certificate).

Activity events aren't [webhook events](/webhooks/events). Webhooks notify your server about a smaller set of changes as they happen. The activity log is the complete record, which you read when you need it.

## Read the activity log

To read a document's log, call [`GET /documents/{id}/activity`](/api-reference/get-document-activity-log). It needs the `READ_DOCUMENT_AUDIT_LOG` workspace permission. The response lists every event, newest first:

```json
{
  "activity": [
    {
      "id": "cm4k2x9p90011abcd4567klmn",
      "createdAt": "2026-10-01T09:41:05.000Z",
      "type": "DOCUMENT_SIGNED",
      "data": {},
      "name": "Kai Berg",
      "email": "kai@example.com"
    }
  ]
}
```

| Field | Description |
|-------|-------------|
| `id` | The event ID. |
| `createdAt` | When the event happened. |
| `type` | The event type, from the following tables. |
| `data` | Event-specific details. Its shape depends on `type`. |
| `name`, `email` | The person who caused the event, when known. |

The response leaves out IP addresses, user agents, and request metadata. Treat `type` as an open list: sajn can add new types without a new API version.

## Delivery

| Type | Description |
|------|-------------|
| `EMAIL_SENT` | An invitation email was sent to a party. |
| `SMS_SENT` | An invitation SMS was sent to a party. |
| `REMINDER_SENT` | A reminder was sent to a party. |
| `REMINDERS_STOPPED` | Automatic reminders stopped. |
| `DELIVERY_DELIVERED` | An email was delivered. |
| `DELIVERY_BOUNCED` | An email bounced. |
| `DELIVERY_FAILED` | An email couldn't be delivered. |
| `DELIVERY_COMPLAINED` | The recipient marked an email as spam. |
| `DELIVERY_SUPPRESSED` | An email wasn't sent, because delivery to the address is suppressed. |

## Parties

The party event types keep their original names, from before the API called participants parties.

| Type | Description |
|------|-------------|
| `SIGNER_CREATED` | A party was added. |
| `SIGNER_UPDATED` | A party's details changed. |
| `SIGNER_DELETED` | A party was removed. |
| `SIGNING_URL_ACCESSED` | A party's signing URL was fetched. |
| `SIGNER_VARIABLES_SUBMITTED` | A party submitted the values they fill in before signing. |
| `SIGNER_ATTACHMENT_UPLOADED` | A party uploaded an attachment. |

## Document lifecycle

| Type | Description |
|------|-------------|
| `DOCUMENT_CREATED` | The document was created. |
| `DOCUMENT_SENT` | The document was sent for signing. |
| `DOCUMENT_OPENED` | A party opened the document. |
| `DOCUMENT_READ` | A party read the whole document. |
| `DOCUMENT_VIEWED` | Someone viewed the document. |
| `DOCUMENT_SIGNED` | A party signed. |
| `DOCUMENT_SIGNATURE_MARK_CAPTURED` | A party drew a signature or initials mark. |
| `DOCUMENT_REJECTED` | A party rejected the document. |
| `DOCUMENT_COMPLETED` | Every required party signed, and the document completed. |
| `DOCUMENT_FORCE_COMPLETED` | The document was completed manually. |
| `DOCUMENT_WITHDRAWN` | The document was withdrawn and returned to draft. |
| `DOCUMENT_CANCELLED` | The document was cancelled. |
| `DOCUMENT_RESET` | The document was reset to draft. |
| `DOCUMENT_RECREATED` | The document was recreated. |
| `DOCUMENT_EXPIRATION_EXTENDED` | The expiration date of a sent document moved. |
| `DOCUMENT_DELETED` | The document was moved to the trash. |
| `DOCUMENT_RESTORED` | The document was restored from the trash. |
| `DOCUMENT_ARCHIVED` | The document was archived. |
| `DOCUMENT_UNARCHIVED` | The document was unarchived. |
| `DOCUMENT_DOWNLOADED` | A file of the document was downloaded. |
| `DOCUMENT_API_ACCESS` | The document was read through the API. |
| `DOCUMENT_UNAUTHORIZED_ACCESS` | Someone tried to open the document without access. |
