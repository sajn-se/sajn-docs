The sajn API is a REST API for electronic signing. You create a document, add the people who sign it, send it, and get a sealed PDF back when everyone has signed. Every signature is backed by an eIDAS seal, and parties can sign with Swedish BankID, other Nordic eIDs, or a drawn or click-to-sign signature.

## Make a request

The base URL for every endpoint is the following:

```text
https://app.sajn.se/api/v1
```

Authenticate with an API key in the `Authorization` header, and choose the API version with the `Sajn-Version` header:

```bash
curl https://app.sajn.se/api/v1/me \
  -H "Authorization: Bearer API_KEY" \
  -H "Sajn-Version: 2026-10"
```

Replace `API_KEY` with an API key from **Inställningar > Utvecklare > API-nycklar** in your workspace settings. For more information, see [Authentication](/get-started/authentication).

Requests and responses are JSON, and timestamps are ISO 8601 in UTC. A sandbox uses the same base URL; the API key decides which environment you reach. For more information, see [Sandbox](/get-started/sandbox).

## Pin the API version

sajn versions the API by date, in `YYYY-MM` format. The docs describe `2026-10`. We recommend sending `Sajn-Version` on every request, so your integration keeps working the same way when your organization's default version changes. For more information, see [API versioning](/api-fundamentals/versioning).

## Tools

- **OpenAPI specification:** `https://app.sajn.se/api/v1/openapi`. Use it to generate a typed client.
- **Postman:** import the [starter collections](/get-started/postman).

## Get developer updates

To hear about new endpoints, breaking changes, and deprecations before they ship, turn on developer updates in the sajn app under **Inställningar > Utvecklare**. Updates go to your account's email address.

For help, contact [dev@sajn.se](mailto:dev@sajn.se).
